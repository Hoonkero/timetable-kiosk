# Формат данных

Один JSON-файл на корпус. Минимальный пример:

```json
{
  "schedule": {
    "title": "Расписание на I полугодие",
    "updatedAt": "2026-09-15T08:00:00+03:00",
    "revision": "r12",
    "teachers": { "t1": "Преподаватель 04" },
    "classes": {
      "7А": {
        "displayName": "7А",
        "days": {
          "monday": [
            { "lesson": 1, "time": "08:30–09:10", "subject": "Алгебра",
              "teacher": "Преподаватель 04", "teacherIds": ["t1"], "room": "203" }
          ]
        }
      }
    }
  }
}
```

| Поле урока | Смысл |
|---|---|
| `week: "even" \| "odd"` | урок только по чётным или нечётным неделям (по ISO-номеру недели) |
| `weekMask: "10"` | альтернатива: маска «чётная/нечётная» |
| `actualTeacher` | замена: терминал подсветит урок и покажет «вместо …» |
| `groups` | подгруппы (английский, информатика) |
| `weekendDay: "saturday" \| "sunday"` | для дня `weekend` |

Проверить файлы перед публикацией: `node scripts/validate-data.js data/*.json`.
