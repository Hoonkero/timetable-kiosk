# Timetable Kiosk

Интерактивное расписание для школы: классы, преподаватели, корпуса и замены. Статический интерфейс на JavaScript, HTML и CSS без сборки и сторонних библиотек.

**[Открыть демонстрацию](https://hoonkero.github.io/timetable-kiosk/)** · **[Другие проекты портфолио](PORTFOLIO.md)**

## Задача и решение

Пользователь выбирает класс или преподавателя и получает расписание по дням. Интерфейс принимает JSON, показывает уроки нужной чётности недели, выделяет замену преподавателя и сохраняет выбор в адресе страницы.

- Настройки корпусов и источников данных вынесены в `config.js`.
- Последнее загруженное расписание хранится в IndexedDB с резервным localStorage.
- При недоступности источника данных можно показать сохранённое расписание с пометкой об отсутствии сети.
- Данные опрашиваются раз в минуту; обновление учитывает ревизию.
- В интерфейсе используются крупные элементы управления и поддержка prefers-reduced-motion.

## Запуск

```sh
git clone https://github.com/Hoonkero/timetable-kiosk.git
cd timetable-kiosk
python3 -m http.server 8080 --bind 127.0.0.1
```

Открыть http://127.0.0.1:8080/ . Формат входных данных описан в [data/README.md](data/README.md).

## Проверка

```sh
node scripts/validate-data.js data/north.json data/river.json
```

29.10.2026 проверку прошли оба демонстрационных файла: 9 и 5 классов. Данные содержат условные обозначения преподавателей. В этой проверке не измерялись производительность и доступность для всех вспомогательных технологий.

## Ограничения

Кешируется расписание, а не вся страница: холодный запуск без сети не гарантируется. Сервер конвертации расписания, учётные записи и реальные школьные данные не входят в проект. Публичная версия показывает возможности интерфейса и не является подтверждением промышленного внедрения.
