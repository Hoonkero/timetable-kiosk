# Changelog

## v1.0.0 — 2026-09-18
Первый публичный релиз. Терминал вынесен из внутреннего портала и отвязан от бэкенда.
- Выбор класса → подгруппы → расписание дня; режим «Учителя» с расписанием по преподавателю
- Чётные и нечётные недели, замены учителей, подгруппы, выходные дни
- Офлайн: последняя удачная версия хранится в IndexedDB (с запасным localStorage), бейдж «сохранённая версия»
- Автообновление раз в минуту, перерисовка только при смене `revision`/`updatedAt`
- Состояние (корпус, класс, учитель, день) хранится в URL, поэтому ссылку можно сохранить
- Конфигурация в `config.js`, демо-данные двух корпусов, валидатор данных, демо на GitHub Pages
