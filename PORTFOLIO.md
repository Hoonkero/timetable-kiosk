## Что посмотреть в коде

- **Расписание:** отделение конфигурации от интерфейса, нормализация JSON, фильтрация уроков и резервное чтение кеша.
- **Диспетчер:** разделение классификации, политики и выполнения; сохранение состояния обращения; тесты ограничений действий.
- **OBS:** HTTP Upgrade, challenge-response, сопоставление запросов и ответов, обработка ошибок и таймаутов.

## Границы демонстраций

Диспетчер работает с демонстрационным транспортом: адаптер живого MAX в публичную версию не входит. OBS проверялся на локальном тестовом сервере, без подключения к реальному эфиру; клиент не поддерживает TLS, события и сборку фрагментированных сообщений. Кеш расписания не гарантирует холодный запуск страницы без сети.

Проекты предназначены для просмотра кода и локального воспроизведения. Из README каждого проекта доступны команды запуска и тестирования. Рабочие аккаунты, данные пользователей, внутренние адреса и закрытые интеграции в эту подборку не включены.
